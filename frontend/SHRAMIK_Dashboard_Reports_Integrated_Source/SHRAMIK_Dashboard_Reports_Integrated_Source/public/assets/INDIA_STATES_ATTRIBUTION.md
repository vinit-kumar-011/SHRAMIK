# India State / Union Territory Boundary Data

The bundled `india-states.geojson` file is copied without geometry transformation from `Vardhan-Systems/vardhan-maps`, file `src/data/generated/states.low.json` (36 state/UT features).

- Upstream attribution notes: https://github.com/Vardhan-Systems/vardhan-maps/blob/main/ATTRIBUTION.md

The upstream data is derived from OpenStreetMap and has editorial border corrections. It is a best-effort visualization dataset, not a Survey of India product, not survey-grade, and not appropriate for legal or official boundary decisions. Verify authoritative boundaries with the Survey of India before official use.

The polygons are for map geometry only. They do not supply labour-market metrics, establish regional completeness, or justify rendering missing analytical values as zero. SHRAMIK map fills must come only from compatible scenario results returned by the active data adapter.
