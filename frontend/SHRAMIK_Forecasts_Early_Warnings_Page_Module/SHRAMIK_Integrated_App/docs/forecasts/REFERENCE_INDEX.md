# Forecasts Design Reference Index

## Required reference hierarchy

1. `Forecasts_Five_View_Design_Board.png` — main page/view composition reference. The five mini screenshots represent alternative internal views of one workspace, not five simultaneous panels.
2. `views/01-Forecast-Overview.png` — default view structure.
3. `views/02-Risk-Radar.png` — risk matrix, selected state and detail layout.
4. `views/03-Scenario-Analysis.png` — conditional scenario comparison.
5. `views/04-Model-Performance.png` — backtesting, error metrics, coverage and limitations.
6. `views/05-Alert-Management.png` — alert workflow and history.
7. `SHRAMIK_Dashboard_Reference.png` — authority for global shell/sidebar/topbar and canvas.
8. `Forecasts_Command_Centre_Concept.png` — additional styling reference for the combined command-centre concept. It is denser than the final five-view approach; do not render all of its panels together if they belong in separate tabs.

All text, data values, chart data, state colouring, risk levels, alerts and metrics in generated images are illustrative. Build interface components from actual frontend code and adapter responses, never set a screenshot as the entire page.
