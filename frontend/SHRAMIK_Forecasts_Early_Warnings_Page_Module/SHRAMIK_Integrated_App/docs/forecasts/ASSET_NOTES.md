# Asset Notes

## Included decorative assets

- `assets/shared/hero-worker-industrial.png`
- `assets/shared/sidebar-workers.png`
- `assets/shared/industrial-skyline.png`
- `assets/shared/dot-grid-accent.png`

These are optional reusable decorative assets from the shared SHRAMIK dashboard design package. Reuse existing hosted/shared paths in the app if those assets already exist; avoid duplicating files into a second asset directory during integration.

## Maps

Do **not** use `india-map-illustrative.png` or any generated screenshot map to shade regional values. A data map requires accurate state/UT geometry, canonical codes and verified state-level forecast/risk values. The included reference images are for visual direction only.

## Fonts

Follow the shared app's existing font loading/token setup. Do not bundle or install duplicate font files unless the repository's design system specifically requires them.
