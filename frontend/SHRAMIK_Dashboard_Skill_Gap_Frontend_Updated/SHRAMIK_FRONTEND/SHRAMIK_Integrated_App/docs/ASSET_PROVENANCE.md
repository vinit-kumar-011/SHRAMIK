# Asset provenance and use

The PNGs in `public/assets/` are **individual visual assets** cropped from the approved SHRAMIK dashboard concept and its associated generated asset board. They are supplied to preserve the chosen visual direction during development; they are not production data visualisations.

- `hero-worker-industrial.png`: hero decoration derived from the dashboard mockup; an editorial crop with some original halftone/dot treatment retained.
- `sidebar-workers.png`: construction-worker illustration used near the bottom of the desktop sidebar.
- `india-map-illustrative.png`: illustrative map crop only; it is **not** a reliable state-boundary map and must not encode real metrics.
- `sticky-note-decorative.png`: decorative sticky-note art from the concept. Its lettering is baked into the illustration; use it decoratively only.
- `industrial-skyline.png`: optional illustration derived from the generated style board.
- `yellow-sun-texture.png`, `dot-grid-accent.png`, `accent-circles.png`: standalone reusable decorative PNGs. The global dotted canvas itself is implemented in CSS so it stays consistent across pages.

These are convenience crops rather than pristine vector masters; replace them in place with refined/licensed standalone illustrations if needed. Keep the same composition, light editorial palette and asset filenames where possible. Do not embed metrics, map legends, interface copy or navigational labels inside artwork.
