# SHRAMIK Landing Page — Revised Package

This package contains a refined SHRAMIK landing-page implementation in both standalone HTML and React component form.

## Files
- `SHRAMIK_Landing_Page_v2.html` — open directly in a browser for the standalone prototype.
- `SHRAMIK_Landing_Page_v2.md` — matching page content/specification.
- `SHRAMIKLandingPage.tsx` + `SHRAMIKLandingPage.module.css` — componentized React implementation for SHRAMIK's Vite/TypeScript frontend.
- `vite-env.d.ts` — Vite type reference for CSS modules.
- `SHRAMIK_LANDING_PAGE_INTEGRATION.md` — integration and test checklist.

All demo chart content is illustrative. No backend, authentication provider or forecast model is invoked by this page.
