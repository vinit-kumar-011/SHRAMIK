Sensitivity analysis requires a separate analytical run

Sensitivity analysis explores how results change as one or more input parameters vary across a declared range. This is computed by the backend/model service — not re-scaled from the current run.

What will be analysed:
• Varied: Additional annual training seats (10K → 200K in 10K steps)
• Fixed: Training lag 2 yrs, Start 2027, Geo: India, Eval: 2030
• Result metric: Skill gap at evaluation year

Sensitivity analysis is distinct from uncertainty bands or a single run. Curves are not drawn from re-scaling the current run.
