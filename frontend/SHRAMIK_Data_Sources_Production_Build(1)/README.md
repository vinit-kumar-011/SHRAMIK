# SHRAMIK Data Sources — dashboard-shell aligned preview

Open `index.html` in a browser. The standalone page bundles its CSS, JavaScript and worker image; no npm installation is required for the preview. The visual shell follows `docs/reference/SHRAMIK_Dashboard_Reference.png`: warm dotted full-width header, flush-left full-height navigation, canonical route order, and worker artwork/callout anchored at the bottom.

Data is the labelled `SYNTHETIC_DEMO` fixture. The REST adapter in the source archive requires real endpoint/auth configuration and backend verification before live use.
