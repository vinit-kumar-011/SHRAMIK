# Scenario Simulator — Asset Notes

- `reference/scenario-simulator-design-board.png` is a composite concept board. It is not a webpage screenshot captured from a running implementation.
- `reference/scenario-simulator-primary-layout.png` is a crop of the primary mockup for layout review.
- `reference/results-overview-reference.png`, `sector-impact-reference.png` and `sensitivity-analysis-reference.png` are smaller crops from the lower strip of the composite image. They help distinguish the intended alternate result states; they are not pixel-perfect implementation screenshots.
- `reference/SHRAMIK_Dashboard_Reference.png` is the existing approved dashboard shell reference. Reuse the actual shell code where available rather than trying to reconstruct it from this image.
- Worker/industrial artwork is decorative only. Reuse the canonical worker artwork already owned by the shared shell. If no separable hero asset exists, isolate it only as an asset task; do not use the whole mockup as a background image.
- The dots should be implemented with the global CSS canvas/pattern token.
- Charts, sliders, tables, toggles, tooltips, outputs and maps must be real UI components bound to adapter responses. Never crop these out of the concept and ship them as images.
- All figures in all concept images are illustrative placeholders.
