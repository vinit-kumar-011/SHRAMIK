# SHRAMIK

Evidence-driven Labour Market Intelligence & Skill Shortage Early-Warning Platform.

## Repository layout
- backend/ — backend application and tests
- data/ — source register and data workspace
- docs/ — architecture, API, data, database, methodology and frontend contracts
- frontend/ — React + TypeScript + Vite frontend foundation

## Run the frontend
    cd frontend
    npm install
    npm run dev

Production build:
    npm run build

Read frontend/README.md and docs/frontend/SHRAMIK_GLOBAL_DESIGN_SYSTEM.md before adding pages. Demo values in the showcase are illustrative and are not official or live labour-market data.
